🛰️ GreenPath System Flow & Architecture Diagram

Interactive dataflow schematic displaying the 5-stage deep learning and mathematical modeling pipeline.

1️⃣ OpenCV Preprocessing Engine

Before feeding the orthomosaic tiles into the convolutional model, GreenPath runs high-pass grayscale filters and Gaussian kernels to balance color distributions. A custom HSV greenness color boundary mask isolates coordinates of dry/green regions, minimizing non-veg pixel noise for object inference.

2️⃣ Deep Learning Canopy Extraction (YOLOv8)

The core bounding box extractor is powered by a YOLOv8 (small variant) architecture with custom anchors. Pretrained weights are fine-tuned on 2,500 annotated high-res satellite tree crowns. Bounding box coordinates output target location parameters and dynamic prediction confidence percentages.
